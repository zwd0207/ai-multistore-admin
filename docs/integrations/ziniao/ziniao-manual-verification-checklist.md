# 紫鸟人工登录核对清单

> 本清单供项目负责人在本机手工登录后核对。不要把任何 ID、密钥、Token、手机号、密码、Cookie、签名或请求头粘贴到聊天、截图或工单中。

## 1. 登录与企业绑定

入口：<https://open.ziniao.com/login>

公开登录方式：手机验证码、密码、紫鸟账号登录。

| 核对项 | 页面路径 | 需要查看的字段/状态 | 通过标准 |
|---|---|---|---|
| 开放平台账号 | 登录页 → 登录 | 当前登录主体和账号类型 | 确认是预期企业账号 |
| 紫鸟企业绑定 | 控制台首页 | 是否已绑定紫鸟企业账号 | 显示已绑定且企业唯一 |
| 企业认证 | 控制台 → 企业认证 | 企业认证状态、办理人、管理员身份 | 已完成；操作人有合法权限 |
| BOSS/成员身份 | 控制台首页或账号信息 | 当前账号是 BOSS 还是成员 | 明确权限边界，不混用 |

只记录“通过/未通过/待处理”，不要记录身份证、手机号或企业证件原值。

## 2. 卖家自研应用

入口：控制台 → 应用管理 → 目标“紫鸟浏览器卖家应用” → 设置/应用概览。

| 核对项 | 需要查看 | 通过标准 |
|---|---|---|
| 应用唯一性 | 应用名称、类型、所属企业、状态 | 只有一个明确用于本项目的应用 |
| 鉴权模式 | 简单通用模式/复杂鉴权模式 | 首期优先简单通用模式；不得同时混用 |
| 应用审核 | 审核状态、失败原因 | 已通过或明确仍未批准 |
| API Key/密钥状态 | 仅看“已生成/未生成”、更新时间 | 不复制明文；确认可轮换 |
| 应用有效状态 | 启用/停用、创建人、更新时间 | 状态明确，责任人明确 |
| 成员应用审批 | 成员创建时的 BOSS 审核 | 审核链完整 |

## 3. 接口权限

入口：应用概览 → 接口权限/开放能力。

首个只读阶段只需核对以下权限是否存在、是否已批准：

- 获取当前自建应用的公司信息。
- ERP-账号查看权限。
- ERP-查询某用户有权限的账号列表。
- ERP-员工查询。
- ERP-设备查询。
- ERP-设备历史绑定记录。
- 标签列表或店铺标签只读能力。

必须明确拒绝或保持未申请：

- 创建/删除账号。
- 新增/删除/清除账号授权。
- 设备购买、续费、绑定、解绑、自动续费。
- 员工新增、修改、启用禁用、部门变更。
- 角色、权限和访问策略写入。
- SSO 用户 Token、Webdriver、CLI 执行权限，除非后续单独审批。

记录字段：权限官方名称、申请状态、审批时间、审批人角色、可用范围、是否只读。不要记录凭证值。

## 4. 安全中心和 IP 白名单

入口：应用概览 → 安全中心 → IP 白名单。

核对：

- 是否必须固定公网 IP。
- 是否允许多个 IP。
- IP 变更是否需要重新审核。
- 未在白名单时的安全错误码。
- 是否存在测试环境或临时白名单。
- 白名单修改是否有审计记录。

只记录规则结论和状态，不记录当前真实 IP。

## 5. 频率、错误码和版本

入口：应用概览 → 接口和调试工具；每个已申请接口详情。

公开文档没有给出统一值，需要人工逐项查看：

- QPS、分钟/日配额。
- 分页最大 `limit`。
- 429/限流错误码及重试建议。
- 权限不足、IP 白名单、签名、Token 过期错误码。
- API 当前版本、发布日期、废弃日期、替代接口。
- SDK 推荐版本；重点核对 Java 5.0.6 与 ERP-Demo 5.1.0 的差异。

记录时只抄录公开规则和错误码，不复制调试请求、请求头或响应原文。

## 6. 公司、店铺、员工和设备样本字段

入口：接口和调试工具，只在负责人明确批准的只读核对中使用。当前阶段不要执行。

未来人工核对字段：

| 对象 | 需确认字段 | 目的 |
|---|---|---|
| 公司 | 公司 ID 是否固定唯一 | 确定公司级连接作用域 |
| 店铺 | store ID、名称、平台、站点、标签、状态 | 建立人工确认映射 |
| 平台账号 | 是否返回登录账号；是否可隐藏 | 隐私和展示设计 |
| 设备 | proxy/device ID、类型、IP 标签、地区、到期、套餐、续费状态 | 工作台健康提醒 |
| 员工 | user ID、用户名、状态、部门、角色 | 建立脱敏候选绑定 |
| 授权 | 用户与店铺关系、附加账号权限 | 对比内部 RBAC |

样本核对结果只保存字段存在性、类型和脱敏示例，不保存完整原始响应。

## 7. SSO

入口：应用权限 → `获取指定用户登录token`；文档：<https://open.ziniao.com/docSupport?docId=145>。

需确认：

- 权限是否必须联系客服和 BOSS 验证。
- Token 的真实 `expireTime/timeUnit`。
- Token 是否一次性、能否重复消费、是否可撤销。
- 用户、店铺和本地登录账号不一致时的行为。
- 客户端最低版本和 Windows 限制。
- 本地已登录同一用户时是否可省略 Token。
- `lanuchUrl`、调试端口、下载路径等参数是否需要额外审批。
- 打开错店后的阻断和审计能力。

不要实际获取 Token 或打开店铺，直到单独批准 SSO 微测试。

## 8. Webdriver

入口：控制台首页 → 自动化/通讯录同步 → Webdriver 设置。文档：<https://open.ziniao.com/docSupport?docId=99>。

需确认：

- 当前企业是否已开通 Webdriver。
- 是否只能由 BOSS 开启。
- 允许使用的专用自动化账号。
- 账号是否有“查看账号”权限。
- Windows/macOS/Linux 客户端实际版本。
- 是否必须关闭登录验证。
- 本地 HTTP 服务是否只监听 `127.0.0.1`。
- `--listen_ip` 是否被禁用或受控。
- API 输入是否仍要求公司名、用户名和密码。
- 是否存在不含明文密码的替代授权方式。

本项目在没有安全替代凭证方案前，不进入 Webdriver 开发。

## 9. CLI

入口：用户应用管理 → 紫鸟 CLI 应用 → 设置 → 终端管理；公开指南：<https://open.ziniao.com/docSupport?docId=281>。

需确认：

- CLI 应用所属账号和审核状态。
- 权限清单是否可精确限制为只读。
- 成员账号与 BOSS 账号的差异。
- 已绑定终端列表和终端识别码管理。
- 终端撤销、丢失处理和凭证轮换。
- CLI 操作日志、失败记录和审计可见性。
- 是否可禁止页面点击、文件上传和平台写入。
- 是否支持只列店铺而不启动店铺。

当前阶段不要安装、初始化或授权 CLI。

## 10. 回调

入口：开放平台控制台 → 设置 → 消息推送回调配置；公开文档：<https://open.ziniao.com/docSupport?docId=247>。

需确认：

- 安全管家剩余时长是否大于 300 天。
- 可配置的回调 URL 和 HTTPS/证书要求。
- 回调签名、源地址校验、重放保护是否存在。
- 四个核心接口的权限状态。
- 事件唯一 ID、投递 ID 和去重键。
- 5/15/45 分钟重试之外的失败处理。
- 截图 URL 权限、24 小时过期和下载审计。
- 服务到期后的数据保留和补发机制。

在签名、去重和隐私边界未确认前，不接收真实回调。

## 11. SkillHub 和包下载异常

人工可在浏览器打开任一失败 Skill：

`https://open.ziniao.com/skillHubDetail?id={id}`

需确认：

- 页面上的“下载 Skill 包”是否在已登录状态下可用。
- 74 个 `test-agent-files-sz.linkfox.com` 链接返回 403 是否是临时签名、权限或失效问题。
- 包内输入输出、第三方凭证、平台写入和日志规则。
- Skill 是否有版本历史、废弃标记和更新日期。

不要安装或执行包，只需下载到隔离目录后静态查看说明。

## 12. 人工核对完成后的交付格式

只需返回以下非敏感结果：

```text
ENTERPRISE_BOUND: yes/no
APP_UNIQUE: yes/no
AUTH_MODE: simple/complex/unknown
READ_PERMISSIONS_APPROVED: [官方权限名称]
WRITE_PERMISSIONS_APPROVED: none/[官方权限名称]
IP_WHITELIST_RULE: 已确认/未确认
RATE_LIMIT_RULE: 已确认/未确认
SSO_PERMISSION: approved/not_approved/unknown
WEBDRIVER_ENABLED: yes/no/unknown
CLI_APP_STATUS: approved/not_approved/not_created
CALLBACK_READY: yes/no/unknown
BLOCKER: 非敏感原因码
```

不得附凭证、Token、真实公司/店铺/员工 ID、请求头、Cookie 或原始响应。
