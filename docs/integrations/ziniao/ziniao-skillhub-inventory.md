### 2.1 ID 118 卖家自研 ERP 对接

- 来源：B 类 SkillHub，公开 Skill 包可读。
- 用途：说明账号、设备、访问策略、角色权限、部门员工五个 ERP API 模块。
- 输入：API Key、对应接口权限、公司 ID，以及各接口业务字段。
- 输出：网关层与业务层双层响应。
- 权限：简单通用模式 Bearer API Key；公开包列出各模块权限点。
- 风险：高。包含创建/删除店铺、授权、设备购买/绑定、员工/角色/访问策略写入。
- 当前项目：仅把其作为文档参考；不能直接执行。
- 版本问题：包内写 72 个接口和账号组 22 个，当前公开目录已经是 74 条记录、账号组 24 个。
- 确认状态：官方文档确认；包内接口数量与当前公开目录冲突，数量需更新核对。

### 2.2 ID 119 卖家自研 Webdriver / CDP 对接

- 来源：B/C 类，公开 Skill 包和官方文档可读。
- 用途：本地启动紫鸟客户端、列店铺、开关店铺窗口、返回调试端口，再连接 Selenium/Playwright 等。
- 输入：本地端口、公司/用户名/密码、`browserOauth` 或店铺 ID、插件和启动参数。
- 输出：状态码、店铺列表、`debuggingPort`、`core_version`、运行信息。
- 权限：BOSS 开通 Webdriver；建议专用成员账号；本机客户端必须满足版本要求。
- 风险：高。需要登录凭据、启动店铺、修改/下载内核、清理缓存，并可继续执行平台页面操作。
- 当前项目：本阶段禁止。后续也不得设计指纹伪装、验证码绕过或风控规避。
- 确认状态：官方文档确认。

### 2.3 ID 120 SSO 单点登录

- 来源：B/C 类，公开 Skill 包和官方文档可读。
- 用途：查询公司、员工和店铺，获取指定用户登录 Token，再用 `superbrowser://` 拉起客户端。
- 输入：API Key 或复杂鉴权材料、`companyId`、`userId`、`storeId`。
- 输出：公司 ID、员工/店铺列表、短期用户 Token、客户端启动结果。
- 权限：`user-login` 需申请权限，公开包提示可能需要客服和 BOSS 验证。
- 风险：高。Token 泄露、错店启动和跨用户调用都可能造成严重后果。
- 当前项目：可作为未来“一键打开正确店铺”的协议参考，但不进入第一项真实只读测试。
- 确认状态：官方文档确认。

### 2.4 ID 121 linkfoxai 图片工具

- 来源：B 类，公开 Skill 包可读。
- 用途：图片上传、场景裂变、商品替换、自动抠图、异步结果查询。
- 输入：图片 Base64 或 HTTPS URL、提示词、尺寸、任务 ID 等。
- 输出：任务 ID、状态、图片 URL、宽高、格式、错误码。
- 权限：Bearer API Key；公开包要求从本地配置读取，不能照搬其“让用户提供并写配置”的提示到本项目。
- 风险：中。会上传商品素材并产生外部处理结果，但不等于 Naver/Coupang 商品写入。
- 当前项目：可在未来商品媒体模块评估；不属于紫鸟店铺接入第一阶段。
- 确认状态：官方文档确认。
