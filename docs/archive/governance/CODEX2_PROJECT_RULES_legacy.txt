# Codex 2 项目目标、项目规划与执行规则

## 一、Codex 2 项目角色

Codex 2 负责本项目的 **前端 UI、页面结构、交互流程、mock 数据、状态展示和业务页面原型**。

项目名称：

AI 多店铺运营与环境管理系统

当前阶段重点：

先完成可运行的前端后台，让系统具备完整页面框架、业务表格、操作按钮、mock 数据和后端接口对接预留能力。

Codex 2 不负责真实 Naver / Coupang API 调用。真实 API 由 Codex 1 后端完成。Codex 2 先用 mock 数据开发，后续由 Codex 3 统一接入真实后端接口。

---

## 二、Codex 2 项目目标

第一阶段前端目标如下：

1. 搭建 React 前端项目。
2. 实现左侧菜单、顶部栏、主内容区。
3. 实现首页驾驶舱。
4. 实现店铺管理页面。
5. 实现店铺详情页面。
6. 实现平台账号 / API 凭证页面。
7. 实现 API 同步日志页面。
8. 实现商品数据页面。
9. 实现订单数据页面。
10. 实现客服 / 咨询数据页面。
11. 实现销售额统计页面。
12. 实现设备环境页面。
13. 实现店铺邮箱 / 重点邮件页面。
14. 实现申诉资料页面。
15. 实现 AI 日报上下文页面。
16. 实现 mockApi.js。
17. 预留真实后端 API 对接方式。
18. 保证中文和韩文显示正常。
