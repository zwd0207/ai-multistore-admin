| 当前术语或表述 | 面向运营的业务说法 | 处理方式 |
| --- | --- | --- |
| API / 接口 / API 资料 | 店铺连接资料 | 管理员区域 |
| API 密钥、Client ID、Access Key、Secret | 店铺连接密钥 | 管理员区域，默认隐藏 |

| 本地同步 / 本地记录 | 系统已保存的记录 | 不出现“本地”时可省略 |

| 写入边界、writeback、gate | 提交发货信息到平台 | 发货确认页使用 |
| dry-run / preview | 提交前检查 | 发货确认页使用 |

| 受控开放 | 需人工确认后提交 | 用于真实平台动作提示 |

## 3. 仓库发货状态文案

| 系统状态 | 操作员可见标题 | 说明和下一步 |
| --- | --- | --- |
| 可进入发货 | 待发给仓库 | 请确认货号和库存后，创建发货批次。 |
| SKU 缺失 | 商品货号待确认 | 此商品还没有对应仓库货号，请补充后再发给仓库。 |
| 库存异常 | 仓库库存不足 | 当前库存不足，不能加入发货批次，请联系仓库确认。 |
| 已创建批次 | 等待发送仓库 | 仓库表已准备好，请下载并发送给仓库。 |
| 已发仓 | 已发给仓库，等待回传 | 仓库发货后会填写快递公司和运单号，请导入回传表。 |
| 回传导入 | 仓库回传待检查 | 系统已读取回传表，请处理需要确认的订单。 |
| 可回填 | 待提交发货信息 | 信息已检查完成，请确认后提交到平台。 |
| 提交中 | 正在提交发货信息 | 请不要重复点击或关闭页面。 |
| 成功 | 平台发货信息已提交 | 平台已收到物流信息，订单已完成发货处理。 |
| 失败 | 发货信息提交失败 | 请查看失败原因，修正后单独重试。 |
| 已取消 | 订单已取消，不能发货 | 请不要发送给仓库；若仓库已发出，立即联系仓库处理。 |
| 运单冲突 | 运单号需要确认 | 此运单号已用于其他不相关订单，请检查仓库回传表。 |
| 快递不支持 | 快递公司待确认 | 请从平台支持的快递公司中选择后再提交。 |
| 数量不符 | 发货数量待确认 | 仓库实际发货数量与订单不同，请确认后继续。 |

## 4. 发货测试场景

| 场景 | 准备条件 | 预期结果 |
| --- | --- | --- |
| 正常发货 | 同店铺、未取消订单，SKU 已匹配、库存足够，仓库表含合法快递和运单号 | 可创建批次、下载仓库表、导入后显示“待提交发货信息”，人工确认后成功提交。 |
| SKU 未匹配 | 平台商品或选项没有内部货号 | 订单进入“商品货号待确认”，不能加入发货批次。 |
| 库存不足 | SKU 映射存在，但可用库存小于订单数量 | 订单进入“仓库库存不足”，不能生成批次。 |
| 批次内重复运单 | 同一批次两个无关订单使用相同运单号 | 阻止提交，显示涉及订单和“运单号需要确认”。 |
| 合法合单 | 同一收件人、同一订单拆分商品，仓库规则允许共用运单 | 标记为“需确认”而非直接失败；人工确认理由后允许继续。 |
| 历史重复运单 | 运单号已在其他未完成或已完成发货记录中使用 | 默认阻止；仅管理员按明确合单规则可解除。 |
| 取消订单 | 创建批次前或回填前订单被取消 | 阻止进入批次或阻止提交；显示“订单已取消，不能发货”。 |
| 快递公司错误 | 回传表快递名称无法映射到平台支持项 | 标记“快递公司待确认”，不得提交。 |
| 运单号为空或格式错误 | 回传表缺少运单号或含明显非法字符 | 标记“物流信息不完整”，不得提交。 |
| 数量不一致 | 仓库实际发出数量与订单数量不同 | 标记“发货数量待确认”，要求填写说明或拆分处理。 |
| 混入其他店铺订单 | 当前批次中导入其他店铺或平台的订单行 | 阻止导入，明确显示不属于当前批次的订单。 |
| 平台回填失败 | 平台拒绝某一条发货信息 | 已成功行保持完成；失败行保留中文原因和单独重试入口，禁止整批重复提交。 |
| 双击提交 | 操作员连续点击提交按钮 | 只形成一次提交记录；页面显示“正在提交发货信息”。 |
| 刷新页面 | 已创建批次、已导入回传表或已有失败记录 | 批次、回传结果和提交结果仍能恢复，不依赖浏览器临时状态。 |

## 5. 常用客服回复模板分类

模板均应支持运营修改后再发送；涉及退款、投诉、假货、平台处罚的模板必须转人工主管确认。

| 分类 | 建议模板 |
| --- | --- |
| 发货前咨询 | 什么时候发货、订单处理中、周末或节假日安排、地址确认 |
| 物流查询 | 已发货待揽收、运输中、物流停滞、配送完成、配送失败或退回 |
| 商品咨询 | 尺码建议、颜色和规格、库存情况、使用方法、正品说明 |
| 订单变更 | 修改地址、取消订单、合并订单、缺货替代方案 |
| 售后服务 | 退货申请、换货申请、退款进度、漏发和错发、商品损坏 |
| 风险和投诉 | 正品证明、延迟致歉、投诉安抚、平台审核资料已提交 |
| 日常礼貌 | 已收到咨询、感谢购买、补充信息请求、处理结果通知 |

## 6. 新运营人员最可能困惑的十件事

1. 顶部当前店铺与页面内“全部店铺”筛选到底哪个决定发货提交范围。
2. 发货辅助究竟是生成表、发送仓库、导入回传表，还是直接填写平台物流单号。
3. “生成发货表格”后是否已经发给仓库，是否可以安全刷新页面。
4. 平台订单号、商品订单号和内部编号分别在哪里用，是否都要填写。
5. 订单为什么不能发货，是货号未匹配、库存不足、已取消，还是已经进入其他批次。
6. 仓库返回表中的哪些列能填写，哪些关键订单字段不能改。
7. 运单号相同到底是错误还是合单；系统如何要求人工确认。
8. 客户问发货进度时，为什么还要在订单、物流群和客服页面之间来回查找。
9. 页面上的“同步”“数据源”“只读”“写入边界”是否会影响自己正常处理订单。
10. 发货失败后应在哪里修正、能否重试、会不会把已经成功的订单重复提交。
