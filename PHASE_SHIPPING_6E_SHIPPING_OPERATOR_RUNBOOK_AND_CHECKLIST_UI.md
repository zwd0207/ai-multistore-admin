# Phase Shipping-6E: Shipping operator runbook and checklist UI

Purpose: give ordinary operators a simple shipping workflow checklist.

Checklist:

1. Download unshipped orders.
2. Maintain logistics inventory codes.
3. Export the logistics-provider Excel file.
4. Import tracking-number records.
5. Readonly-match tracking numbers to local orders.
6. Ask an admin for a separately approved shipment writeback phase.

This UI is informational only. It does not create tasks, update orders, or call Naver.
