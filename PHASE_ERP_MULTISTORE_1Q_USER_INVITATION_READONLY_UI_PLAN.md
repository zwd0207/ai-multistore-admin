# Phase ERP-Multistore-1Q: User Invitation Readonly UI Plan

Purpose: plan a seller/admin-readable UI for user invitation readiness without sending invitations or creating users.

UI direction:

- Add a separate Accounts-page panel for user invitation readiness.
- Show business wording for whether later invitation approval can be planned.
- Keep hashes, phase, skip reason, write flags, and audit flags in folded technical details.
- Do not show complete email, phone, password, token, request headers, signature, or raw response.

Safety:

- Real invitation remains closed.
- Real user creation remains closed.
- Real login sessions remain closed.
- Store membership writes remain closed.
- Multi-user production access remains closed.
